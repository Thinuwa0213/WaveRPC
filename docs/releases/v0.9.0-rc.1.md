# WaveRPC Release Candidate Notes (v0.9.0-rc.1)

WaveRPC connects browser music playback (SoundCloud) to Discord Rich Presence using a 100% local-first, privacy-respecting bridge architecture.

This Release Candidate (`v0.9.0-rc.1`) is the final staging release prior to `v1.0.0` general availability.

---

## 🚀 Key Highlights & Capabilities

- **Local-Only WebSocket Bridge**: The Desktop application binds strictly to `127.0.0.1:6124`. No data ever leaves your device.
- **Discord IPC Pipe Auto-Discovery**: Automatically scans Windows named pipes `\\.\pipe\discord-ipc-0` through `9` with resilient auto-reconnect.
- **SoundCloud Real-Time Presence**: Dynamic album artwork, track title, artist, elapsed/remaining timestamps, and provider badge with direct link action buttons.
- **Spotify-like Pause**: Pausing playback clears Discord Rich Presence immediately while keeping local application state intact.
- **Timing Authority State Machine**: Handles scrubbing, seeks, tab switches, and network reconnections with zero timestamp jitter.
- **Multi-Tab Audio Coordination**: Automatically tracks active audio tabs and switches presence cleanly when alternating playback across multiple browser tabs.
- **Zero Telemetry / Privacy First**: `PrivacySanitizer` cleanses URLs, strips query tokens, and prevents tracking data leakage.
- **Un-elevated User Installer**: NSIS installer installs to `%LOCALAPPDATA%\Programs\WaveRPC` without administrator privileges required.

## 🔧 Installation & Verification

### 1. Install WaveRPC Desktop

1. Run `WaveRPC-Setup-0.9.0-rc.1.exe`.
2. Follow the setup wizard (installs to user local AppData).
3. WaveRPC will launch and sit in your system tray.

### 2. Install WaveRPC Extension

1. Extract `WaveRPC-Extension-0.9.0-rc.1.zip` to a local folder.
2. Open `chrome://extensions/` in Chrome or Brave.
3. Enable **Developer mode** (top right toggle).
4. Click **Load unpacked** and select the extracted folder (containing `manifest.json`).

### 3. Start Listening

1. Ensure the Discord Desktop app is open and running.
2. Play any track on [SoundCloud](https://soundcloud.com).
3. Rich Presence will reflect on your Discord profile within seconds!
