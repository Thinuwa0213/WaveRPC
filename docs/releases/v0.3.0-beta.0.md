# WaveRPC v0.3.0-beta.0 Release Notes

**Release Date**: August 26, 2026  
**Release Stage**: Beta (`v0.3.0-beta.0`)

WaveRPC `v0.3.0-beta.0` is the Beta milestone release for the WaveRPC platform. It delivers release hardening, enhanced error handling, schema validations, and automated packaging improvements.

---

## 📦 What's Included

This Beta release hardens the core application, packaging, and validation workflows:

- **Port Conflict Native Dialog**: Distinguishes socket port conflicts (`EADDRINUSE`) from other startup failures and displays a native error dialog warning the user before exiting cleanly.
- **Strict Input Validation**: Hardens the desktop WebSocket bridge handler with type safety checks validating all incoming JSON structures.
- **Tray Event Handler Cleanup**: Unsubscribes status change listeners during system tray destruction to prevent event listener leaks.
- **Monorepo Version Bump**: Upgraded all modules and application versions across the monorepo to `0.3.0-beta.0`.
- **Dynamic Version Tests**: Removed hardcoded expectations from tests, allowing them to automatically track version changes.

---

## ⚡ Stability & Robustness Improvements

- **Fail-Fast Beta Packaging**: Configured the build pipeline to run typechecking, linting, formatting checks, and the full test suite before packaging the installer and extension.
- **Zero Registry Leaks**: OS startup entry registry keys are automatically deleted when WaveRPC is uninstalled.
- **Independent Packaged Execution**: Packaged desktop builds execute successfully on clean machines without requiring `.env` files or repository environments.

---

## ⚠️ Known Limitations & Compatibility

1. **Official Discord Desktop Client**: Requires the official Discord Desktop client to be active on the host machine.
2. **SoundCloud Focus**: SoundCloud is currently the primary supported streaming service.
