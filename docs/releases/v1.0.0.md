# WaveRPC v1.0.0 General Availability Release Notes

WaveRPC is a universal, local-first music Rich Presence platform that connects your browser media playback directly to Discord Rich Presence without external servers or cloud accounts.

This is the first stable production **General Availability (GA)** release (`v1.0.0`).

---

## 🌟 Supported Features & Capabilities

- **SoundCloud Web Playback Integration**:
  - Real-time extraction of track title, artist name, duration, elapsed timestamp, and album artwork.
  - Interactive "Listen on SoundCloud" button embedded directly in Discord Rich Presence.
- **Precision Timing Authority**:
  - Synchronous elapsed and total duration countdown timers.
  - Immediate forward and backward scrubbing/seek recovery with zero timestamp drift or jitter.
  - Graceful handling of temporary player buffering and DOM delays.
- **Spotify-like Pause Behavior**:
  - Pausing SoundCloud clears your Discord Rich Presence status immediately (`{ activity: null }`).
  - Retains current track metadata locally within the WaveRPC Desktop dashboard.
  - Resuming playback immediately restores presence with the exact elapsed time.
- **Multi-Tab Audio Coordination**:
  - Automatically identifies the actively playing SoundCloud tab across multiple browser windows.
  - Automatically transfers presence authority when playing a different tab.
  - Reverts cleanly to paused tabs or clears presence without metadata leakage when tabs are closed.
- **Local-Only & Privacy-First Architecture**:
  - 100% loopback communication strictly bound to `ws://127.0.0.1:6124`.
  - Zero external telemetry, zero analytics, and zero cloud accounts.
  - Automated `PrivacySanitizer` cleanses URLs and strips access tokens or tracking parameters.
- **Desktop System Integration**:
  - Direct Discord IPC named pipe discovery (`\\.\pipe\discord-ipc-0` through `9`).
  - Automatic Discord reconnection with exponential backoff if Discord restarts.
  - Single-instance application lock with window focusing.
  - Native Windows port conflict dialog box on `EADDRINUSE`.
  - System tray minimization with live status indicators and un-elevated startup registry support.
- **Security Hardening**:
  - Strict WebSocket message schema validation.
  - Defensive 100 KB payload size limit.
  - Sandboxed renderer with Node integration disabled and context isolation enabled.

## 🚀 Installation & Setup

### 1. Install WaveRPC Desktop

1. Download and run `WaveRPC-Setup-1.0.0.exe`.
2. Complete the setup wizard (installs to `%LOCALAPPDATA%\Programs\WaveRPC` without requiring admin elevation).
3. WaveRPC will launch and sit in your Windows system tray.

### 2. Install WaveRPC Extension

1. Extract `WaveRPC-Extension-1.0.0.zip` to a local folder.
2. Open Chrome or Brave and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (toggle in upper right corner).
4. Click **Load unpacked** and select the extracted folder (the directory containing `manifest.json`).

### 3. Usage

1. Ensure the Discord Desktop application is open and running.
2. Open SoundCloud in your browser and play any track.
3. Your Discord profile will automatically display rich music presence!

## ⚠️ Known Limitations

- **Unsigned Binary (SmartScreen)**: As an open-source release built without a commercial EV code signing certificate, Windows SmartScreen will display an _"Unknown Publisher"_ prompt on first launch. Click _"More info"_ → _"Run anyway"_.
- **Supported Provider Scope**: Currently, SoundCloud is the sole officially supported streaming service in v1.0.0. Other services are planned for future releases.
- **SoundCloud Web Player DOM Changes**: SoundCloud updates to their web player HTML/CSS structure may require future extension updates for compatibility.
- **Discord Desktop Required**: Discord Web in a browser cannot receive local IPC pipes. The official Discord Desktop application must be running.
